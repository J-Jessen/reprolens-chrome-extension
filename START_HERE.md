# Start here – ConsoleHawk public beta

Download `consolehawk-v0.11.1-beta.1.zip` from the [official GitHub release](https://github.com/J-Jessen/consolehawk-chrome-extension/releases/tag/v0.11.1-beta.1). Do not use GitHub's automatic source archive. You do not need to change any code.

Before installing, you can see the product, watch the walkthrough, and open the safe demo on the [public beta page](https://j-jessen.github.io/consolehawk-chrome-extension/).

The package is provided for evaluation and feedback under the terms in `LICENSE.md`.

1. Read the safety section in `BETA_TEST_GUIDE.md`.
2. Follow the installation and testing steps in the same guide.
3. Use one copy of `BETA_BUG_REPORT.md` for each distinct problem.
4. Complete `BETA_FEEDBACK_FORM.md` when you finish testing.
5. Submit sanitized feedback through the repository's public issue forms. Contact the owner privately if the report contains a security or privacy concern.

Test only on local or staging websites that you are authorized to inspect. Never share credentials, cookies, tokens, private keys, customer data, or a trace that you have not reviewed yourself.

When you finish testing, remove the extension through `chrome://extensions`, then delete the ZIP file and the extracted folder if you no longer need them.
