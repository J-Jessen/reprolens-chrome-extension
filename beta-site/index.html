WHY CHROME SHOWS A DEBUGGING BANNER

Deep evidence, deliberately limited access.

Chrome displays its standard debugging banner while ConsoleHawk observes the short interaction. Capture stops automatically, and the extension requests access only to the website you explicitly choose.

Request and response bodies, headers, cookies, form values, typed characters, debugger scopes, and remote runtime objects are not intentionally captured.
