Privacy policy

ReproLens is local-first. Trace collection, source-map resolution, quality scoring, history, feedback, and export redaction run inside the browser extension. ReproLens has no backend, analytics, advertising, account system, or automatic upload.

Website access

ReproLens has no required website access and no always-on page recorder. Chrome requests access to the exact HTTP or HTTPS website only after you start element selection, a single trace, or a user journey. Access remains limited to that origin and can be revoked in Chrome's extension settings.

Data handled during a trace

A user-started trace can process selected-element metadata, capped text and HTML, interaction type, source locations, request URL and metadata, navigation URLs, console messages, runtime errors, asynchronous boundaries, and summaries of visible page changes. A journey can retain up to 30 interaction summaries for up to two minutes.

Request and response bodies, HTTP headers, cookies, storage values, typed characters, form values, submitted values, dropped data, debugger scopes, and remote runtime objects are not intentionally captured.

Local storage and retention

ReproLens can keep up to 25 completed traces within a 5 MB local application budget. The oldest records are removed first when a limit is reached. You can disable history, delete individual traces, clear all history, clear beta feedback, or uninstall ReproLens to remove its extension storage according to Chrome's normal behavior.

Exports and third parties

Nothing is sent automatically. Copy and download actions remain on your device. If you explicitly open a GitHub issue draft, the reviewed and redacted report is placed in a GitHub URL and is transmitted to GitHub when that page loads. ReproLens does not submit the issue and does not request or store a GitHub token.

Optional on-device explanation

On supported Chrome devices, you may explicitly request a second explanation from Chrome's on-device language model after reviewing its redacted input. ReproLens has no cloud AI fallback and does not transmit the prompt to the developer.

Data sharing and sale

ReproLens does not sell user data, share it with advertisers, or use it for creditworthiness, lending, advertising, or purposes unrelated to its browser-debugging function.

Changes and contact

This policy will be updated before ReproLens changes its data practices. Privacy questions can be raised through the project's support page. Report a possible exposure privately through GitHub private vulnerability reporting.
